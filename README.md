# Kaleidoscope · กล้องสลับลาย

Extension ของ SillyTavern ที่ใช้ **ธีม + BG เป็นเซท** แล้วเลือกเซทให้เองตามแชท บอท หรือเวลา
ไอเดียมาจากระบบสุ่มธีม/เปลี่ยนธีมตามเวลาของ Tauri Tavern และใช้กับ SillyTavern ตัวหลักได้

## ติดตั้ง

Extensions → Install extension → ใส่ลิงก์

```
https://github.com/inathael-58/SillyTavern-Kaleidoscope
```

## ใช้งาน

1. เปิดแผง **Kaleidoscope** ใน Extensions แล้วกด **จัดการเซท** (หรือเลือก Kaleidoscope จากเมนูไม้กายสิทธิ์)
2. แท็บ **เซท**: สร้างเซท ทีละเซทคือธีมหนึ่งธีมคู่กับ BG หนึ่งภาพ
   - **จากที่ใช้อยู่** เก็บธีมและ BG ที่ใช้อยู่ตอนนี้เป็นเซท
   - ธีมที่ตั้งเป็น "ธีมปกติของฉัน" หมายถึงไม่เปลี่ยนธีม ใช้ธีมที่คุณเลือกเองใน ST
   - BG ที่ตั้งเป็น "BG ปกติ" หมายถึงไม่เปลี่ยน BG
   - **ใช้ช่วงไหน**: ติดแท็ก กลางวัน / กลางคืน / ทั้งคู่ ให้เซท
   - **ไม่เอาเซทนี้เข้ากฎสุ่ม** สำหรับเซทที่ตั้งใจใช้กับแชทหรือบอทบางตัวเท่านั้น
   - เลือกการวางภาพ (cover / contain …) แยกต่อเซทได้ หรือใส่ลิงก์รูปเองได้
   - **ลองใช้** ใส่เซทนั้นชั่วคราว จนกว่าจะเข้าแชทใหม่
3. แท็บ **แชทนี้ / บอทนี้**: แตะเซทเพื่อผูกกับแชทหรือบอทที่เปิดอยู่
4. แท็บ **กฎการเปลี่ยน**: ตั้งเวลากลางวัน/กลางคืน และเลือกโหมดการเปลี่ยนเซท

### ลำดับความสำคัญ

**แชทนี้ › บอทนี้ › กฎสุ่ม**

เซทที่ผูกกับแชทหรือบอท **ชนะกฎสุ่มเสมอ** ระดับไหนไม่ได้ผูกเซทไว้จะส่งต่อให้ระดับถัดไป
ถ้าไม่มีระดับไหนตัดสินเลย จะคืนธีมและ BG ปกติของคุณ

- **แชทนี้** เก็บไว้ในไฟล์แชท
- **บอทนี้** ใช้กับทุกแชทของบอทตัวนั้น (หรือกลุ่มนั้น)
- **กฎสุ่ม** สุ่มจากทุกเซท (ยกเว้นเซทที่ติ๊ก "ไม่เอาเข้ากฎสุ่ม") ให้แชทที่ไม่ได้ผูกเซท

### กลางวัน / กลางคืน

ตั้ง **กลางวันเริ่ม** กับ **กลางคืนเริ่ม** ครั้งเดียวในแท็บกฎการเปลี่ยน แล้วทุกเซทที่ติดแท็กจะใช้ช่วงนี้ ไม่ต้องตั้งเวลาให้ทีละเซท

- ถ้ายังไม่ได้ตั้งเวลา **กฎเวลาจะไม่ทำงาน** แท็กกลางวัน/กลางคืนจะยังไม่มีผล
- เซท "ทั้งคู่" ใช้ได้ทั้งกลางวันและกลางคืน
- แชท/บอทที่ผูกทั้งเซทกลางวันและกลางคืน (หรือเซท "ทั้งคู่") จะสลับตามเวลาเอง
- แชท/บอทที่ผูกแต่เซทกลางวันหรือกลางคืนอย่างเดียว จะใช้เซทนั้นทุกช่วงเวลา ชนะกฎเวลาเสมอ (หน้าจอจะเตือนไว้)
- **เปลี่ยนทันทีเมื่อเข้ากลางวัน/กลางคืน** เปลี่ยนเซทให้ทันทีขณะแชทเปิดค้าง เฉพาะตอนข้ามกลางวัน/กลางคืนเท่านั้น

### โหมดการเปลี่ยนเซท

| โหมด | ทำงานอย่างไร |
|---|---|
| สุ่มใหม่ทุกครั้งที่เปิดแชท | สุ่มจากทุกเซท หรือสุ่มเฉพาะเซทที่ตรงกับกลางวัน/กลางคืน |
| ตามรอบเวลา | ทุก 1 / 6 / 12 / 24 ชม. นับจาก 0:00 ตามนาฬิกาจริง · เลือกให้ตามกลางวัน/กลางคืนได้ |

- โหมดนี้ใช้กับทั้งกฎสุ่มและเซทที่ผูกกับแชท/บอท (ความถี่เดียวกัน)
- ตัวเลือก "สุ่มจากทุกเซท / ตามกลางวัน-กลางคืน" มีผลกับกฎสุ่มเท่านั้น แชท/บอทดูแท็กของเซทที่ผูกไว้เสมอ
- รอบเวลา + กลางวัน/กลางคืน: เปลี่ยนทั้งตอนข้ามรอบและตอนข้ามกลางวัน/กลางคืน
  เช่น กลางวัน 06:00–18:00 ทุก 12 ชม. → 00:00 เซทกลางคืน · 06:00 เซทกลางวัน · 12:00 สุ่มเซทกลางวันใหม่ · 18:00 เซทกลางคืน
- ข้ามรอบเวลาธรรมดาระหว่างที่แชทเปิดค้าง จะรอเปลี่ยนตอนเปิดแชทครั้งถัดไป
- **ไม่ซ้ำเซทเดิมติดกัน** เมื่อสุ่มใหม่จะไม่ได้เซทเดิมซ้ำ (ถ้ามีมากกว่าหนึ่งเซทให้เลือก)

### อัปเดตจาก v1.2 ลงมา

กติกาเดิมของแท็บ "ตามเวลา" ถูกแปลงเป็นกฎสุ่มให้อัตโนมัติ (รายวัน → ทุก 24 ชม.) เซทที่ไม่ได้อยู่ในกติกาเดิมจะถูกติ๊ก "ไม่เอาเข้ากฎสุ่ม"
เซทที่ผูกกับแชท/บอทยังอยู่ครบ ส่วนช่วงเวลา วันในสัปดาห์ และน้ำหนักของแต่ละรายการถูกเลิกใช้ ให้ติดแท็กกลางวัน/กลางคืนแทน

### BG ที่ล็อกกับแชท

ถ้าแชทมี BG ที่ล็อกไว้ด้วยปุ่มล็อกของ SillyTavern เอง BG นั้นจะชนะเซทจากบอทและกฎสุ่ม
(ธีมของเซทยังเปลี่ยนตามปกติ) แต่เซทที่กำหนดในระดับแชทจะชนะ BG ที่ล็อก ปิดได้ที่ **เคารพ BG ที่ล็อกกับแชท**

### ธีมปกติ

เมื่อคุณเปลี่ยนธีมเองใน User Settings ธีมนั้นจะถูกจำเป็น "ธีมปกติ" และใช้เมื่อเซทไม่ได้กำหนดธีม หรือไม่มีกติกาไหนตรงกับตอนนี้

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/kal-open` | เปิดหน้าจัดการเซท |
| `/kal-reroll` | สุ่มเซทใหม่ คืนชื่อเซทที่ได้ |
| `/kal-set ชื่อเซท` | ลองใช้เซทจนกว่าจะเข้าแชทใหม่ · ไม่ใส่ชื่อ = คืนชื่อเซทที่ใช้อยู่ |
| `/kal-debug` | รายงานตรวจสอบ |

## อัปเดต

กด **ดึงเวอร์ชันล่าสุด** ในแผง Kaleidoscope ระบบจะดึงโค้ดใหม่จาก GitHub ล้างไฟล์เก่าที่เบราว์เซอร์จำไว้ แล้วถามว่าจะโหลดหน้าใหม่เลยไหม
ป้ายเวอร์ชันข้างชื่อ Kaleidoscope บอกเวอร์ชันที่หน้านี้รันอยู่ ถ้าขึ้นเป็น "v1.x → v1.y" แปลว่าติดตั้งตัวใหม่ไว้แล้วแต่เบราว์เซอร์ยังใช้ไฟล์เก่าอยู่ กดปุ่มเดียวกันนี้ได้เลย

## มีปัญหา

กด **ตรวจสอบ** ในแผง Kaleidoscope แล้ว **คัดลอก** รายงานส่งให้ผู้พัฒนา

```
npm test
```
