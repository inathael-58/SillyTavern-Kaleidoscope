# North Star

Extension ของ SillyTavern ที่ใช้ **ธีม + BG เป็นเซท** แล้วเลือกเซทให้เองตามแชท บอท หรือเวลา
ไอเดียมาจากระบบสุ่มธีม/เปลี่ยนธีมตามเวลาของ Tauri Tavern แต่กำหนดได้ละเอียดกว่า และใช้กับ SillyTavern ตัวหลักได้

## ติดตั้ง

Extensions → Install extension → ใส่ลิงก์

```
https://github.com/inathael-58/SillyTavern-North-Star
```

## ใช้งาน

1. เปิดแผง **North Star** ใน Extensions แล้วกด **จัดการเซท** (หรือเลือก North Star จากเมนูไม้กายสิทธิ์)
2. แท็บ **เซท**: สร้างเซท ทีละเซทคือธีมหนึ่งธีมคู่กับ BG หนึ่งภาพ
   - **จากที่ใช้อยู่** เก็บธีมและ BG ที่ใช้อยู่ตอนนี้เป็นเซท
   - ธีมที่ตั้งเป็น "ธีมปกติของฉัน" หมายถึงไม่เปลี่ยนธีม ใช้ธีมที่คุณเลือกเองใน ST
   - BG ที่ตั้งเป็น "BG ปกติ" หมายถึงไม่เปลี่ยน BG
   - เลือกการวางภาพ (cover / contain …) แยกต่อเซทได้ หรือใส่ลิงก์รูปเองได้
   - **ลองใช้** ใส่เซทนั้นชั่วคราว จนกว่าจะเข้าแชทใหม่
3. แท็บ **แชทนี้ / บอทนี้ / ตามเวลา**: กำหนดว่าระดับนั้นใช้เซทไหนได้บ้าง

### ลำดับความสำคัญ

**แชทนี้ › บอทนี้ › ตามเวลา**

ถ้าระดับบนไม่ได้กำหนด ปิดอยู่ หรือไม่มีเซทที่ใช้ได้ในเวลานั้น จะส่งต่อให้ระดับถัดไป
ถ้าไม่มีระดับไหนตัดสินเลย จะคืนธีมและ BG ปกติของคุณ

- **แชทนี้** เก็บไว้ในไฟล์แชท
- **บอทนี้** ใช้กับทุกแชทของบอทตัวนั้น (หรือกลุ่มนั้น)
- **ตามเวลา** ใช้กับทุกแชท เป็นค่าตั้งต้นของทั้งระบบ

### การเปลี่ยนเซท

| โหมด | ทำงานอย่างไร |
|---|---|
| ทุกครั้งที่เปิดแชท | สุ่มใหม่ทุกครั้งที่เข้าแชท |
| ตามรอบเวลา | สุ่มใหม่เมื่อข้ามรอบ เช่นทุก 1 ชั่วโมง (นับตามนาฬิกา: 10:00, 11:00 …) |
| รายวัน | สุ่มวันละครั้ง ตั้งเวลาเริ่มวันใหม่ได้ (เช่น ตี 4) |
| ตามช่วงเวลา | ใช้เซทตามช่วงเวลา/วันที่ตั้งไว้ในแต่ละรายการ |

- **ไม่เปลี่ยนระหว่างที่แชทเปิดค้าง** ทุกโหมดจะเปลี่ยนเซทตอนเข้าแชทเท่านั้น
  ยกเว้นโหมด "ตามช่วงเวลา" ถ้าเปิดตัวเลือก **เปลี่ยนตามช่วงเวลาทันที** ในแผง Extensions
- แต่ละรายการตั้ง **น้ำหนัก** ได้ (มาก = ออกบ่อย, 0 = ไม่ออก) และตั้ง **ช่วงเวลา** กับ **วัน** ได้ในทุกโหมด
  เช่น สุ่มรายวันจาก 3 เซท แต่เซทหนึ่งออกได้เฉพาะเสาร์-อาทิตย์
- ช่วงเวลาข้ามเที่ยงคืนได้ (22:00–06:00) วันที่ติ๊กไว้นับจากวันที่ช่วงเวลาเริ่ม
- **ไม่ซ้ำเซทเดิมติดกัน** เมื่อสุ่มใหม่จะไม่ได้เซทเดิมซ้ำ (ถ้ามีมากกว่าหนึ่งเซทให้เลือก)

### BG ที่ล็อกกับแชท

ถ้าแชทมี BG ที่ล็อกไว้ด้วยปุ่มล็อกของ SillyTavern เอง BG นั้นจะชนะเซทจากระดับบอทและเวลา
(ธีมของเซทยังเปลี่ยนตามปกติ) แต่เซทที่กำหนดในระดับแชทจะชนะ BG ที่ล็อก ปิดได้ที่ **เคารพ BG ที่ล็อกกับแชท**

### ธีมปกติ

เมื่อคุณเปลี่ยนธีมเองใน User Settings ธีมนั้นจะถูกจำเป็น "ธีมปกติ" และใช้เมื่อเซทไม่ได้กำหนดธีม หรือไม่มีกติกาไหนตรงกับตอนนี้

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/ns-open` | เปิดหน้าจัดการเซท |
| `/ns-reroll` | สุ่มเซทใหม่ คืนชื่อเซทที่ได้ |
| `/ns-set ชื่อเซท` | ลองใช้เซทจนกว่าจะเข้าแชทใหม่ · ไม่ใส่ชื่อ = คืนชื่อเซทที่ใช้อยู่ |
| `/ns-debug` | รายงานตรวจสอบ |

## มีปัญหา

กด **ตรวจสอบ** ในแผง North Star แล้ว **คัดลอก** รายงานส่งให้ผู้พัฒนา

## พัฒนา

```
npm test
```

เทสตรรกะการเลือกเซท (`engine.js`) ด้วย `node --test` ไม่ต้องเปิด SillyTavern
